# Documentos protegidos

Los documentos catalogados durante la migración no se publican desde esta ruta.
Las copias preservadas están en el respaldo local del Paso 5 y requieren
almacenamiento privado y autorización antes de enlazarse desde la plataforma.

No colocar PDFs restringidos en esta carpeta pública.

La excepción V1 son los dos brochures entregados por el cliente y autorizados
para descarga pública, ubicados en `public/` y enlazados desde `/classes.html`.
